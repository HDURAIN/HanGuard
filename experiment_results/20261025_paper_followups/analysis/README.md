## 机制结论的边界

- 类别共享查询仍保留类别向量参与最终打分；不能用它证明所有类别向量无效。
- 五分类专属注意力较共享注意力的平均提升应报告，同时保留不确定性。
- 组合相对末 token MLP 的提升不能全部归于融合；应看组合减类别读出以及同容量重复末层。
- 九臂对应系统对照由相同预测派生；它不等于仅在二分类 gate 加融合的经典组合。
- 共享卡运行速度仅用于进度估算；本模块正式效率数字必须来自空卡并通过进程隔离监测。
