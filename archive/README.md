# 历史归档

这里保存清理前的代码和必要来源证据，不是活动训练目录。所有归档均在项目根目录内部，清理不会处理服务器其他目录。

- `repository_before_cleanup_20260928.tar.gz`：清理前的脚本、测试、README 和研究文档；对应 JSON 保存归档 SHA256。
- `data_before_repair_20260928.tar.gz`：翻译修复依赖的历史三份 split 与元数据。归档不作为默认训练输入。
- `old_experiments_20260928.tar.gz`：被清理实验的轻量协议、摘要、预测和审计材料。旧大权重、特征缓存不在该归档中。
- `legacy_misc_20260928.tar.gz`：根目录旧 `final_*` 三集及类别权重、`legacy` 下的历史脚本与日志，已退出活动目录。
- `old_root_artifacts_20260928.tar.gz`：旧输出根目录日志、运行标记与历史评估文件。
- `source_provenance/`：历史 WildGuard 原文恢复所需的最小本地辅助资料。

精确成员、归档校验与删除记录见 `outputs/repository_cleanup_20260928/`。已完成实验的原协议和保留代码快照保持原样；新训练入口只向新目录注册，不修改历史哈希。恢复旧流程时应使用对应快照，不能混用清理后的新代码与历史注册信息。

归档文件仅本地保存，不进入 Git。若需要完全重现旧权重训练，须从对应数据和代码快照重新运行；清理不承诺保存每个旧检查点。
