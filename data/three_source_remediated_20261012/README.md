# 三来源整改数据 20261012

本版共 **83,502** 条，训练／验证／测试为 **66,802／8,350／8,350**。原来源二分类标签没有修改；已确认的翻译问题、历史误删和切分结构问题已整改，并完成独立验收。旧数据和实验原样保留。

| 来源 | 旧版 | 本版 |
|---|---:|---:|
| WildGuard 中文 | 43,165 | 45,777 |
| 中文整理语料 | 26,918 | 26,925 |
| JailBench | 7,603 | 10,800 |

恢复 **5,817** 个来源身份：5,155 个筛选恢复单位和662个已通过来源及字面检查的旧隔离区单位；另合并1个原文规范化身份重复，因此净增5,816行。恢复范围包含全部原来缺失的长wrapper，JailBench的20类模板、540个父seed和10,800个原始行均有完整映射。1,814条旧review/error译文继续隔离，详见整改输出目录的pending表；它们没有自动升为合格译文。

**218个独立单位的已确认译文错误已修正。** 其中1,952个恢复的WildGuard原文完整新译，固定200条随机样本与高信号全文审查后修53条；661个复用旧译的恢复单位另固定随机审100条并修23条。主集旧确认队列、已知词义族及同中文译文碰撞检查也纳入整改。所有修正保存完整原文/旧译/新译及SHA，并经非作者回读；不补全来源自身的未完成内容，不据模型分数重写文本。

项目类型冲突的 **2,689** 条记为 `category_id=-1`、`type_label_mask=False`，保留原binary监督，不提供类型监督。已知安全类0的mask也为False，但仍参加二分类和有真值的六类门控评估。类型子集见 `../hanguard_two_source_remediated_20261012/`，只取本版同split的native已知类型行，没有再次切分。

分组连接完整公开原文身份、旧父family、同binary标点族、228对已审近邻和JailBench父seed；近邻只作split家族，不能据此删除不同载荷。身份规范化采用NFKC/casefold/去Cf/去空白，不等同原始字节相同，完整来源指针与变体证据保留。固定seed先平衡来源×binary，再在来源×binary向量完全一致的整组间交换以平衡类型；主15格配额保持不变。native已知有害类型train/test份额偏差最大 **0.608个百分点**。

独立验收重新编码全83,502条，最长 **3,202 tokens**，没有截断。123,059个raw指针及1,209个旧archive aliases守恒；原binary、英文原文与native原文变动均0。ID/原文/中文同文/标点族/已审近邻/父组/seed跨集泄漏均0。三集、manifest与QA以SHA绑定，修改后入口会拒绝注册。

两个诊断视图独立保存，未追加进主训练集：`benign_format_control_view.parquet`共25,932条，用于安全父样本格式敏感性与有害marker参照，衍生安全标签不是新增人工gold；`jailbench_template_holdout_view.parquet`含全部20wrapper按12/4/4留出，测已见payload的新wrapper有害召回，只含positive，不能报告完整二分类accuracy/FPR。主split测未见seed、已见wrapper；模板视图要独立训练，不能把主模型当未见wrapper模型。

新切分与旧训练身份交叉，**旧LoRA/检查点/缓存不能用于新版干净评估**。类型入口要求父模型在匹配本版binary数据上训练，并逐条校验同split来源、文本和标签。

这次整改没有训练分类器，也没有验证准确率或融合收益。来源binary/type标签仍是继承标注；抽审与词义扫描不证明未审译文全部正确，来源歧义与未知语义重复风险仍在。旧test已参与探索，本版不是新盲测的替代品。

验收及逐条证据见 `../../outputs/hanguard_data_remediation_20261012/`，汇总见其中 `report.md`；本目录的 `manifest.json`、`release_qa.json` 和 `split_policy.json` 提供发布及分组证据。
