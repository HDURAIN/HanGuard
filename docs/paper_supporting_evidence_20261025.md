## 2. 方法名称与实现事实

CQA为每个类别学习一个查询，对输入文本的L32有效token分别计算注意力，得到每类文本表征，再由共享打分器根据`[表征, 查询, 表征×查询]`输出每类logit。查询以固定随机高斯向量为种子，通过可训练投影、自由类别残差及归一化生成，与分类头一起优化。它们不是提前训练好的类别摘要，也不是本轮由类别说明文本编码得到的语义原型。主实验采用互斥二分类/五分类softmax交叉熵；底层通用模块的旧多标签说明不能替代本轮训练目标。

MLF读取L8、L16、L24、L32各自的最后有效token，分别归一化、投影后按固定的0.25权重相加，经初始为零的残差映射加入分类表征。固定的是层混合系数，各层投影和残差映射仍参与训练；不是将四层完整token序列逐位置融合。D把同一条文本的融合残差加到每个类别的CQA表征后打分。

### 三种容易混淆的对照

| 实验标识 | token聚合查询 | 是否仍显式使用类别向量打分 | 输出分类器 |
|---|---|---|---|
| `category_shared`、`fusion_category_shared` | 原有类别查询取均值，所有类别共享同一注意力分布 | **是**，保留每类查询及交互项 | 原CQA共享的类别条件打分器 |
| `shared_attention_mlp` | 一个独立的可学习共享query | **否** | 常规MLP输出全部类别logit |
| `mean_pool_mlp` | 无query，有效token投影后取均值 | **否** | 常规MLP输出全部类别logit |

因此，`category_shared`只能检验类别专属的注意力分布是否必要，不能检验“所有显式类别向量是否必要”。两个新增通用池化对照才不使用显式类别查询或类别身份向量。均值池化精确定义为逐token无参数LN→Linear/GELU/LN→有效位置均值，不是直接平均原始隐藏状态。

以下为seed 42/43/44的Accuracy均值±样本标准差，单位%。二分类分母8,350，五分类分母2,180；二分类阈值由验证集确定。

| B：MLF | 94.91±0.04 | 77.89±1.62 | 固定多层融合 |
| C：CQA | 95.86±0.15 | 82.20±1.59 | 类别查询聚合模块 |
| D：CQA＋MLF | 96.12±0.25 | 83.13±0.87 | 主方法 |
| `fusion_repeat_last` | 93.79±0.24 | 77.32±0.97 | B的同容量四路L32输入 |
| `category_fusion_repeat_last` | 95.84±0.26 | 82.43±0.09 | D的同容量四路L32输入 |
| `category_shared` | 95.85±0.27 | 81.82±0.55 | 保留类别条件打分，共享注意力 |
| `fusion_category_shared` | 96.17±0.17 | 82.71±0.80 | 上项加MLF |

| `mean_pool_mlp` | 96.14±0.16 | 82.42±0.97 | 无显式类别向量的通用均值池化 |
| `shared_attention_mlp` | 95.92±0.23 | 82.81±0.59 | 无显式类别向量的独立共享注意力 |

前九臂属于同一主实验，后两项是查看父实验结果后登记的补充对照。补充对照沿用同一数据、骨干、三个seed和验证集选择规则；不能写成整个研究开始前就预登记的同一批比较。

| 配对差值 | 二分类Accuracy变化 / pp | 五分类Accuracy变化 / pp |
|---|---:|---:|
| D−A：完整方法总提升 | +2.267±0.183 | +5.856±0.787 |
| D−C：CQA上增加MLF | +0.255±0.394 | +0.933±1.881 |
| B−同容量重复末层 | +1.122±0.250 | +0.566±1.632 |
| D−同容量重复末层 | +0.279±0.007 | +0.703±0.802 |
| C−`category_shared` | +0.012±0.426 | +0.382±2.087 |
| D−`fusion_category_shared` | −0.056±0.093 | +0.428±0.305 |
| B−验证集选单层 | +0.200±0.018 | +0.612±1.347 |

差值标准差按同seed配对差计算，不能由两组标准差相减得到。D五分类比独立共享注意力平均高0.321个百分点，比均值池化高0.719个百分点；二分类均值池化与D基本持平，前者均值略高0.020个百分点。仅凭三个seed的均值顺序不能把接近的对照写成稳定显著优势。

当前证据支持：完整CQA模块相对末token MLP有明显提升；MLF在同容量对照下有一定附加价值，二分类更稳定；五分类类别专属注意力相对保留类别打分的共享注意力有正向平均变化。当前证据尚不能支持：全部提升主要由“类别向量本身”引起、每类查询稳定显著优于所有通用聚合、MLF在每个seed和每类都改善。尤其D−A是完整方法提升，不能全部称为“多层融合提升”。

### 全层probe

每个任务的32层×3 seed共96个线性probe，仅依据三seed平均验证CE选层；二分类选择L18（验证CE 0.141974，L32为0.160661），五分类选择L32（0.597484）。随后在选定层上训练正式单层MLP，得到上表`probe_selected_single`，它不是线性probe本身的测试成绩，也不是测试集逐层择优。该对照表明二分类末层并非最佳线性可分层；五分类的probe仍偏好末层。线性可分性也不等于该层已被证实能识别局部有害片段。

## 6. 分类别改善与第五类代价

D−C衡量在CQA上增加MLF。救回指C错D对，新增错误指C对D错；条数为三个seed的平均值。

| 真实类别 | 测试support | Recall变化 / pp | 救回 / 条 | 新增错误 / 条 | 净正确变化 / 条 |
|---|---:|---:|---:|---:|---:|
| 1 | 680 | +1.27 | 19.67 | 11.00 | +8.67 |
| 2 | 413 | +7.02 | 32.00 | 3.00 | +29.00 |
| 3 | 276 | +0.60 | 11.67 | 10.00 | +1.67 |
| 4 | 506 | +2.24 | 34.33 | 23.00 | +11.33 |
| 5 | 305 | **−9.95** | 13.67 | 44.00 | **−30.33** |

| 类别 | A的F1 / % | C的F1 / % | D的F1 / % |
|---|---:|---:|---:|
| 1 | 81.55 | 86.93 | 86.30 |
| 2 | 81.60 | 85.32 | 88.39 |
| 3 | 75.87 | 81.43 | 84.36 |
| 4 | 73.77 | 80.87 | 81.52 |
| 5 | 67.69 | 70.05 | 68.38 |

D相对A五个类别的平均F1均提高；但D相对C第五类F1和Recall下降，第一类F1也略降。因此可写“组合取得最高五分类平均Accuracy，并在类别间形成不同权衡”，不能写“融合全面改善各类识别”。来源、长度分层和混淆矩阵有助于描述现象，不能单独证明干扰语句是错误原因。尚无局部有害token金标或受控扰动实验，注意力权重也不是经过验证的因果解释。

二分类指标命名要明确：主结果JSON中的`f1`为有害类F1，A为94.43%；后续分析中的二分类Macro-F1为93.78%。两者都是可用指标，不能把前者冠以Macro-F1标签。

## 7. 在线效率：可用数据与适用范围

效率来自真实在线前向：新tokenization＋传输＋骨干＋分类头/原生生成＋CPU输出，不是缓存特征上的head-only计时。设备NVIDIA RTX A6000，GPU 1，正式测量有290次进程隔离检查；32条固定验证输入，seed42，预热3遍、测量10遍，batch 1/8。原始token长度实际为64–737；1,024仅为选样目标，不能写成实测固定1,024 token或长上下文吞吐。骨干BF16，math SDPA，4个CPU线程；原生Guard最大生成128 token。

| 系统 / 任务 | B1 p50延迟 / ms | B8吞吐 / 条·s⁻¹ | B8 peak allocated / GiB |
|---|---:|---:|---:|
| A / 二分类 | 165.17 | 17.85 | 9.767 |
| D / 二分类 | 192.14 | 18.52 | 9.767 |
| A / 五分类 | 168.18 | 17.83 | 9.767 |
| D / 五分类 | 196.36 | 17.99 | 9.767 |
| A / 双阶段 | 178.14 | 17.76 | 9.767 |
| D / 双阶段 | 196.38 | 17.83 | 9.767 |
| 原生Qwen3Guard-Gen-4B | 1,178.49 | 4.08 | 10.130 |

本轮双阶段系统共享一次骨干前向，始终计算两个head，包括二分类判无害的输入。B8吞吐的细微顺序差异不能据此声称MLF加速；D二分类B1 p50较A约增加16.3%。与原生Guard的时延差异包含骨干、模板和生成输出方式差异，不能全部归因于CQA/MLF。显存为PyTorch peak allocated，不等同于整卡总占用；单卡、少量固定输入样本的测量不代表所有部署条件。

## 8. 当前仍缺的证据

1. **原生、明确覆盖相同五类的现成安全模型对照。** 原生Qwen3Guard的类别空间不等同于本数据五类，不应强行填其五分类成绩；后续核验国标类别模型后可补充。Encoder-Guard对比仍按当前决定搁置。
2. **类别专属查询的独立机制归因。** 已完成强对照须保留；当前可以报告模块改善，不能把通用token聚合带来的改善全部归于类别向量。
3. **局部稀疏有害信号与抗干扰的直接验证。** 来源/长度错误分析只提供相关现象，受控插入干扰、等长改写或token证据验证尚未完成。
4. **独立外部集的泛化确认。** 本轮选择锁定不等于整个项目从未探索测试数据，主文不要使用“全新盲测”表述。

这些缺项不影响整理和报告已完成的消融，但决定论文结论应停留在哪一层。

## 9. 外部模型：已完成参考与后续候选

主文仅使用原生Qwen3Guard-Gen-4B作为现成安全模型对照。另有已完成的 `hfl/chinese-macbert-base` 本地监督五分类参考：Accuracy **81.04±0.63%**、Macro-F1 **79.89±0.71%**，训练/验证/测试同为17,440/2,180/2,180，seed 42/43/44。其骨干和普通五分类头均经过本地监督优化，不能称为原生国标五分类模型；可作为不同规模编码器的补充参考，不替代原生安全模型基线。设置为学习率2×10⁻⁵、weight decay 0.01、最多8轮、patience 2；长文按510个正文token的窗口、128个token重叠处理，文档logit取窗口均值。结果见[external/results.json](../outputs/hanguard_paper_followups_20261025/external/results.json)，方法与Hanguard的差异必须随表说明。

| 候选 | 当前可用于什么 | 当前状态 |
|---|---|---|
| Qwen3Guard-Gen-4B | 官方原生二分类判定；同时报告两种等级合并规则 | 已完成8,350条，主文报告 |
| CHILLGuard-4B | 面向中文安全场景的原生二分类补充 | 官方权重公开可获取，尚未在本数据上运行 |
| 原生相同五类模型 | 本地风险五分类的直接外部比较 | 仍待核验类别定义、权重及原生输出 |
| Encoder-Guard | 暂不纳入当前比较 | 按当前决定搁置，未产生实验成绩 |

[CHILLGuard官方仓库](https://github.com/cswbyu/CHILLGuard)公布了5大类/31细类数据体系；但其[4B发布模型](https://huggingface.co/cswbyu/CHILLGuard-4B)的官方推理示例只要求输出“安全/不安全”。数据具有五类标签不意味着模型原生输出五类，因此目前将它列为二分类候选。2026-10-25核验4B公开模型版本为`47c41ae63a451b35a6537cb0cb89f33a8a2d1a91`，模型权重文件约8.04 GB。本次只核验公开资料与文件元数据，没有下载权重或启动推理，不将作者在其自有测试集上的成绩填入本实验表。
