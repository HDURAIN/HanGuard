- `plan.json`：固定根目录、明确目标清单、逐文件身份、归档成员与保留目录。

- `validation.json`：CPU、GPU 推理一致性及后续边界修复的验证记录。

`cleanup_repository.py` 默认只生成计划；执行需要显式 `--apply`，只处理固定清单，拒绝项目外符号链接以及计划后出现的未知文件。归档成员内容必须逐个通过 SHA256 核验才会删除原文件。完成后重复执行不会删除后来新建的目录。

现有实验协议与源码快照没有按新代码重写。若需要历史重放，请在独立目录核对归档成员并使用对应代码、输入和环境；新训练统一使用 [当前入口](training.md)，另建输出目录登记。
