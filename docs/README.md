# 文档导航

当前论文主线是**类别查询注意力聚合（CQA）＋固定多层残差融合（MLF）**，分别评估安全二分类与风险五分类。写作从2026-10-25整理的材料开始；历史报告中的数据、训练设置和成绩保留用于追溯，不直接填入当前实验表。

| 文档 | 内容与用途 |

| [论文结果包](../experiment_results/20261025_paper_ready/README.md) | 可直接用于写作的CSV与LaTeX表、逐种子结果、原始来源指纹及校验入口 |
