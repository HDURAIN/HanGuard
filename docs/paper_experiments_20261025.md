# 类别查询注意力与固定多层融合：实验部分草稿

本文档整理截至 2026-10-25 已完成且可追溯的实验。主线方法命名为**类别查询注意力聚合与条件评分**（Category-Query Attention，CQA）和**固定多层残差融合**（Multi-Layer Fusion，MLF）。下文的“类别查询”是监督训练得到的参数，不是预先编码好的类别语义向量。表中百分比保留两位小数；“±”为 3 个训练随机种子的样本标准差。

## 1. 任务、数据与评价指标

设置两个相互独立的分类任务：安全二分类区分安全与有害输入；风险五分类在具有已知风险类别标注的有害输入中预测所属类别。五分类不是包含安全类的六分类，也不是将完整二分类测试集直接划成五类。

所有方法使用同一固定数据版本和相同划分。数据按来源与安全标签分层，并约束同源样本组不跨训练、验证与测试集合。二分类包含 WildGuard 中文数据、中文整理数据和 JailBench；五分类采用其中类别标注可用的中文整理数据及 JailBench。

| 任务 | 训练集 | 验证集 | 测试集 | 测试范围 |
|---|---:|---:|---:|---|
| 安全二分类 | 66,802 | 8,350 | 8,350 | 固定测试集全部样本 |
| 风险五分类 | 17,440 | 2,180 | 2,180 | 固定测试集中全部已知类别的有害样本 |

五类分别为：违反社会主义核心价值观相关内容、歧视性内容、商业违法违规、侵犯他人合法权益、无法满足特定服务类型的安全需求。标签继承数据来源中的既有类别体系。该体系参考相关安全标准，但本实验不等同于依据现行国标重新逐条人工标注，也不主张复现其全部细分类边界；类别与标准版本的关系见[类别标准与来源说明](primary_category_standard_review.md)。

二分类主要报告 Accuracy 和有害类 F1，并补充 AUROC 及安全样本误报率 FPR；五分类报告 Accuracy 和 Macro-F1。两个任务分别训练和评价。本文所称测试集是固定的留出集合，不将其描述为从未检查过的盲测集合。数据范围与选择流程以[实验协议](../outputs/hanguard_clean_ablation_20261022/protocol.json)为准。

## 2. 方法与四组消融

Hanguard 分类器以 Qwen3.5-4B 为骨干，使用其 32 个骨干解码层的隐藏状态，隐藏维度为 2,560。固定预训练骨干参数，仅训练分类组件；分类组件中间宽度为 128。

### 类别查询注意力聚合与条件评分（CQA）

令最终层的有效 token 状态为 \(h_t\)，查询维度为 \(d=128\)。每个类别有一个查询 \(q_c\)。二分类训练 2 个查询，分别对应安全和有害；五分类训练 5 个风险类别查询。实际参数化为

\[
q_c=\operatorname{LN}_q\left(P(\operatorname{LN}_0(r_c))+\delta_c\right),\qquad
k_t=\operatorname{LN}_q\left(P(\operatorname{LN}_0(h_t))\right),\qquad
v_t=V(\operatorname{LN}_0(h_t)).
\]

其中，\(r_c\) 是按实验种子生成并固定的高斯随机向量，\(\delta_c\) 为可训练的类别残差，初值为零；\(P\) 和 \(V\) 是可训练投影，\(V\) 包含线性层、GELU 和 LayerNorm。查询由上述参数在任务监督下联合学习，并未使用类别描述文本预训练。查询参数不随输入变化，对 token 的关注权重随输入变化：

\[
\alpha_{c,t}=\operatorname{softmax}_{t\in\mathrm{valid}}
\left(\frac{q_c^\top k_t}{\sqrt d}\right),\qquad
z_c=\sum_t\alpha_{c,t}v_t.
\]

每个类别产生自己的聚合表示，再由条件评分器给出一个类别分数：

\[
s_c=g\left([\widetilde z_c;q_c;\widetilde z_c\odot q_c]\right).
\]

这里 \(g\) 是各类别共用参数的两层 MLP，输入维度为 \(3d\)，隐藏宽度为 \(d\)，输出一个标量。各类别的分数共同进入 softmax 交叉熵；因此本实验是互斥分类，不是独立 sigmoid 的多标签训练，也不是按与类别向量的余弦距离进行分类。

### 固定多层残差融合（MLF）

选取第 8、16、24、32 层的最后一个有效 token 状态。各层经过独立投影，以相同的固定权重融合：

\[
f=W_o\left[\frac14\sum_{\ell\in\{8,16,24,32\}}
V_\ell(\operatorname{LN}_0(h_{\ell,\mathrm{last}}))\right]+b_o.
\]

\(V_\ell\) 为线性层、GELU 和 LayerNorm，层权重始终为 \(1/4\)，不参与学习；投影和输出映射参与训练。输出映射 \(W_o,b_o\) 初始化为零。在 CQA 中，融合通过 \(\widetilde z_c=z_c+f\) 接入每个类别的聚合表示；没有 MLF 时 \(\widetilde z_c=z_c\)。

四组实验如下。A 的“无方法”表示不加入 CQA 或 MLF，仍包含可训练的常规分类头。

| 编号 | 配置 | 具体结构 |
|---|---|---|
| A | 基础 MLP | 最终层最后有效 token → LayerNorm → 128 维线性投影 → GELU → Dropout → 类别线性分类器 |
| B | 基础 MLP + MLF | 在基础 MLP 的 128 维表示上加入固定多层残差，再分类 |
| C | CQA | 最终层 token 状态 → 逐类别注意力聚合 → 类别条件评分 |
| D | CQA + MLF | 在每个类别的聚合表示中加入固定多层残差，再进行类别条件评分 |

A/B 使用相同的基础 MLP 初始化，C/D 使用相同的查询组件初始化；零初始化的融合输出使两对配置各自拥有相同的初始输出。以上定义与[分类组件实现](../scripts/hanguard/clean_ablation_heads.py)、[查询组件实现](../scripts/hanguard/multilabel_heads.py)一致。

## 3. 训练与模型选择

全部配置均从当前固定数据版本重新提取特征并训练，不复用既往实验的特征、分类头或模型选择结果。原始文本直接分词，不套用聊天模板，不截断输入；协议注册的输入长度上限为 4,096 token。两个任务使用相同的 3 个训练种子：42、43、44。实际完成的各组训练均为 12 轮。采用 AdamW，学习率为 \(10^{-3}\)，权重衰减为 \(10^{-3}\)，Dropout 为 0.1，梯度裁剪范数为 5；有效批量大小为 128，按 token 预算 8,192 和最大微批量 32 进行累积。

二分类和五分类均优化 softmax 交叉熵。按验证集交叉熵选择 checkpoint；二分类的有害概率阈值按验证集 Accuracy 选择，五分类使用最大类别分数。checkpoint、阈值等选择完成后再执行对应的测试评价，不按测试指标选择这四组方法的 checkpoint。主表报告三种子的均值和样本标准差，而不是从三个种子中选择最高分。训练与选择细节见[训练实现](../scripts/hanguard/clean_ablation_training.py)和[锁定协议](../outputs/hanguard_clean_ablation_20261022/protocol.json)。

## 4. 核心消融结果与可支持的结论

| 配置 | 二分类 Accuracy（%） | 二分类有害 F1（%） | 五分类 Accuracy（%） | 五分类 Macro-F1（%） |
|---|---:|---:|---:|---:|
| A：基础 MLP | 93.85 ± 0.10 | 94.43 ± 0.10 | 77.28 ± 0.95 | 76.10 ± 0.85 |
| B：基础 MLP + MLF | 94.91 ± 0.04 | 95.41 ± 0.06 | 77.89 ± 1.62 | 76.37 ± 1.65 |
| C：CQA | 95.86 ± 0.15 | 96.23 ± 0.15 | 82.20 ± 1.59 | 80.92 ± 1.83 |
| D：CQA + MLF | **96.12 ± 0.25** | **96.48 ± 0.23** | **83.13 ± 0.87** | **81.79 ± 1.14** |

| 配置 | 二分类 AUROC（%） | 二分类 FPR（%，越低越好） |
|---|---:|---:|
| A：基础 MLP | 98.75 ± 0.01 | 6.50 ± 0.52 |
| B：基础 MLP + MLF | 99.08 ± 0.04 | 5.84 ± 0.57 |
| C：CQA | 99.32 ± 0.01 | **3.51 ± 0.31** |
| D：CQA + MLF | **99.39 ± 0.04** | 3.87 ± 0.40 |

相对于 A，D 的二分类 Accuracy 提高 **2.27 个百分点**、有害 F1 提高 **2.05 个百分点**；五分类 Accuracy 提高 **5.86 个百分点**、Macro-F1 提高 **5.70 个百分点**。D 在这四组配置中的两项任务平均 Accuracy 最高。这支持“CQA 与固定多层残差融合组成的分类器优于指定的最终层末位置 MLP 基线”的结论。

为区分不同对照，以下列出按相同种子配对计算的 Accuracy 差值；差值标准差也是三组配对差的样本标准差。

| 对照 | 二分类 Accuracy 增量（百分点） | 五分类 Accuracy 增量（百分点） |
|---|---:|---:|
| B − A：基础 MLP 上加入 MLF | +1.07 ± 0.08 | +0.61 ± 1.35 |
| C − A：以 CQA 替换基础 MLP | +2.01 ± 0.25 | +4.92 ± 1.13 |
| D − A：组合方法相对基础 MLP | +2.27 ± 0.18 | +5.86 ± 0.79 |
| D − C：CQA 上加入 MLF | +0.26 ± 0.39 | +0.93 ± 1.88 |
| D − B：MLF 基础上采用 CQA | +1.20 ± 0.21 | +5.24 ± 0.76 |

CQA 整体组件相对上述 MLP 的平均提升较大，但这一对照同时改变了 token 聚合、查询交互和评分结构，不能据此把全部收益归因为“类别向量”这个单独因素。MLF 在 CQA 基础上的平均增量为正，但各随机种子的方向不一致：二分类为 −0.19、+0.41、+0.55 个百分点；五分类为 +0.18、+3.07、−0.46 个百分点。因此不将 D − C 表述为已经证实的稳定增益、普遍显著增益或超加性的协同作用。D 的 FPR 也未优于 C，不主张组合方法在所有指标或所有类别上均有改善。

## 5. 原生 Qwen3Guard 对比及解释范围

外部基线使用原版 [Qwen3Guard-Gen-4B](https://huggingface.co/Qwen/Qwen3Guard-Gen-4B)，保持模型权重不变，按官方单用户输入模板直接生成原生安全判定。使用 BF16、贪心解码、最大生成长度 128，不增加系统提示，不截断输入。对同一二分类测试集全部 8,350 条输入完成推理，输出解析覆盖率为 100%。

其原生安全等级包含 Safe、Unsafe、Controversial，因此预先固定并同时报告两种二分类规则：①仅 Unsafe 为有害；②Unsafe 与 Controversial 均为有害。两种规则均保留，不根据测试成绩挑选一个规则代替另一个。

| 模型与规则 | Accuracy（%） | 有害 F1（%） | Macro-F1（%） | FPR（%） | 本地五分类 |
|---|---:|---:|---:|---:|---|
| 原生 Qwen3Guard：仅 Unsafe 为有害 | 90.86 | 91.04 | 90.86 | **0.51** | N/A |
| 原生 Qwen3Guard：Unsafe + Controversial 为有害 | 94.83 | 95.27 | 94.78 | 4.18 | N/A |
| Hanguard，D：CQA + MLF | **96.12 ± 0.25** | **96.48 ± 0.23** | **96.07 ± 0.26** | 3.87 ± 0.40 | 83.13 ± 0.87 |

| Qwen3Guard 规则 | 有害 Precision（%） | 有害 Recall（%） | TP / TN / FP / FN |
|---|---:|---:|---|
| 仅 Unsafe 为有害 | 99.51 | 83.90 | 3,878 / 3,709 / 19 / 744 |
| Unsafe + Controversial 为有害 | 96.53 | 94.03 | 4,346 / 3,572 / 156 / 276 |

D 的平均二分类 Accuracy 分别高于上述两种规则 5.25 和 1.29 个百分点。需要同时说明：Qwen3Guard 此处使用原生零样本直接推理，Hanguard 的分类组件则使用本地任务训练数据监督训练；这一外部比较反映当前使用方式下的任务表现，不能隔离架构改动的因果贡献。Qwen3Guard 的原生风险类别不与本地五类形成唯一对应关系，因此本地五分类填 N/A，不把类别映射或额外训练分类头后的结果标为其原生五分类能力。当前结果也显示了工作点差异：仅 Unsafe 规则的误报很低，但有害召回较低。
