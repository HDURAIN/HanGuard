# hanguard 主要类别标准与来源核查

核查日期：2026-09-28。本文件整理标准与数据来源事实，不启动标注或训练，不修改原始标签。其中对意图重标草案的分析保留为历史决策依据；当前训练继承两来源标签，不执行该草案。**五个主类名称可以共用，但国标 31 项风险、JailBench 40 个细分类型与本地 36 个有数据的细类不能视作逐项相同。**

JailBench 官方分类图在类 1 显列邪教宣传，在类 2 显列种族与性取向歧视，在类 4 显列财产权与公共安全。类 5 保留“不准确／不可靠”的风险说明，数据细分使用医疗、心理、法律、科学、历史、金融六个领域；**领域维度与内容质量维度不是同一层面的两个互斥划分**。见 [官方分类图](https://raw.githubusercontent.com/STAIR-BUPT/JailBench/main/assets/cate.png)。

本地核验对象为 [`JailBench-seed.csv`](../data/sources/jailbench/JailBench-seed.csv) 与 [`JailBench.csv`](../data/sources/jailbench/JailBench.csv)：分别为 540 条和 10,800 条，36 个二级领域各有 15 个种子及 300 个包装后 query。相对官方分类体系，本地没有类 1 的政权颠覆、国家分裂两项，以及类 4 的荣誉权、其他合法权益两项；此结论仅描述现有文件覆盖，不推断缺项原因或代表作者全部内部数据。

## 项目映射与草案定义的差异

历史构建器 `build_academic_dataset.py` 建立一级领域至类别 ID 的映射；`build_three_source_dataset.py` 按领域赋类型，并把所有 JailBench query 设为 harmful。两份脚本现保存在[清理前代码归档](../archive/README.md)中。类型映射保留了来源大类，**全量 harmful 是项目的数据处理口径，不是国标逐条鉴定每个输入文本的结果**。

已归档且停用的 `primary_category_policy.json` 重标草案沿用了此前任务描述，未完成与标准及来源数据的逐项对齐：

- **类 3：** 标准与 JailBench 明确覆盖商业道德、商业秘密、知识产权、垄断及不正当竞争等。草案突出营销欺诈，未明确列齐商业道德、垄断；虽有概括性补充，仍可能使标注器理解偏窄。
- **类 4：** 草案强调具体个人的直接侵害，没有完整呈现荣誉权、财产权、公共安全与其他合法权益的来源范围，确有收窄风险。
- **类 5：** 正式标准关注特定服务的内容准确性与可靠性，其中可靠性还涉及内容能否给使用者带来帮助；不是“不可用／不稳定”的条目，也没有把“用户明确要求模型造假”设为必要条件。草案增加了高风险专业决策以及输入明确索要不可靠内容的条件，属于额外任务适配，不能标成标准原义。
- **类 1：** 标准与 JailBench 均有较宽的其他法律禁止内容条目；草案强调列举行为、不作泛化兜底，同样属于改变操作口径，不能只因为主类名称一致就认为已经对齐。

本地类 5 进一步表明领域标签与草案风险条件并不等价：种子行索引 450、465、495、510 分别涉及陷害他人的法律问题、假支票、历史否认及心理虐待后的自我维护，来源都归为类 5。这里不重新裁决这些样本，只说明不能用新的缩窄定义去解释旧标签已经表达的含义。

## 原文风险定义与只审 prompt 的区别

标准附录面向训练数据及生成内容的风险。hanguard 当前仅看到用户输入，尚未看到模型实际回答；正常医疗或金融问题的未来回答可能准确，也可能错误，不能只凭领域词就认定已产生不准确内容。同样，出现风险主题不自动说明用户请求实施该风险。

因此须明确区分三个对象：**文本请求的风险、有害生成内容的风险、数据来源标注的主要领域**。输入审核可以设计适配规则，但必须写明是研究任务定义，不能暗中缩窄标准后又声称完整复现标准。保留来源标签时，也不能反过来宣称所有原标签都已满足新增适配条件。

## 两来源类型训练是否可行

只用中文整理语料与 JailBench 的现有标签训练五分类类型头，是可行且省去 WildGuard 类型重标的实验路线。它并不要求有害二分类同时弃用 WildGuard；两种监督的使用范围可以分开。训练和推断仍可统一为五分类交叉熵与 softmax argmax。

实验前应固定以下口径：

1. 类型目标明确写为“两来源既有主要风险类别／领域标签”，逐行保留来源与标签继承信息；不声称已按新草案重新审核。
2. 原 split 和 JailBench 种子分组保持不变，所有方法共享训练、验证、测试有效行；按来源报告类型 accuracy、Macro-F1、各类支持量及覆盖率。
3. 两来源类别边界是否一致需另行核查，尤其类 5；不能因五个名称相同就宣布语义金标已经统一。独立复核可在规则冻结后单列开展。
4. 若 WildGuard 类型标签未经复核，不将其类别分数作为主要有效性证据；可以评估其有害二分类。两来源类型测试的结论不能直接扩展为任意中文输入的类型识别能力。

若最终选择严格对齐正式国标，应先恢复完整范围，再规定可从输入判断的操作条件与不能判断的处理方式；若选择保留数据集原口径，则应如实命名任务并报告差异。两条路线都能研究，关键是标准、标注和评价使用同一份已冻结的任务说明。
